# Section 3.4 Change Summarization

1. Select list view, then scroll down to “**Changes”**. Select “**Open**” to get a list of all open Change Records.

<figure><img src="../.gitbook/assets/menu.png" alt="" width="231"><figcaption></figcaption></figure>

2. From the list of open **Changes**, locate and click on “**CHG0030006**”. \[PLATFORM-RELEASE-24.1.2] Quarterly Platform Release Train......

<figure><img src="../.gitbook/assets/2026-08-10 12.50.20.png" alt=""><figcaption></figcaption></figure>

3. For our lab, let's move this change along a bit. Click on Request approval ![](<../.gitbook/assets/2026-08-10 13.52.39.png>)



4. Select the “**Summarize**’ button on the Overview to see the Summary of the Change Request.

<figure><img src="../.gitbook/assets/2026-08-10 13.54.18.png" alt=""><figcaption></figcaption></figure>

**Congratulations,** you have generated your first change summarization! Please **don’t close** your browser or the workspace; we’ll continue exploring it in the next section.
